本模块是仓库根，不包含业务代码，而是集中编排多语言（Rust + Python + JS）子项目的构建与开发体验：
- Bazel 模块入口 `MODULE.bazel` 声明 `codex` 模块，引入 rules_rs、rules_python、llvm、windows_support、protobuf 等扩展，并通过 `archive_override`/`single_version_override` 对 hermetic-llvm、Windows SDK、abseil-cpp 等进行补丁与版本锁定；`BUILD.bazel` 定义本地 Linux/Windows 平台约束与 gnullvm/msvc 双 ABI toolchain，以及禁用 Xcode 的 `xcode_config`。
- Nix flake (`flake.nix`) 基于 nixpkgs + rust-overlay 提供跨平台 devShell 与 package，版本从 `codex-rs/Cargo.toml` 读取。
- pnpm workspace (`package.json`、`pnpm-workspace.yaml`、`pnpm-lock.yaml`) 以 `codex-monorepo` 为私有包名，仅承载 Prettier 格式化脚本与 Node 引擎要求（>=24.22.1, pnpm >=10.34.5），并通过 `resolutions`/`overrides` 锁定第三方依赖。
- `justfile` 作为开发者命令入口，封装 cargo run/clippy/test/bench、Bazel 运行（`bazel-codex`、`bazel-code-mode-host`）、schema 生成（config/app-server/hooks）与 argument-comment lint 等任务，通过 `scripts/just-shell.py` 实现跨平台 shell 执行。
- 辅助文件包括 `.bazelrc`、`.bazelignore`、`rbe.bzl`、`ruff.toml`、`.prettierrc.toml`、`.markdownlint-cli2.yaml`、`.codespellrc` 等质量与规则配置；`workspace_root_test_launcher.{sh,bat}.tpl` 由 Bazel 模板导出供测试使用。
